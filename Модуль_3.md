## Задание 1

### Выполните импорт пользователей в домен au-team.irpo:

- В качестве файла источника выберите файл users.csv располагающийся в образе Additional.iso

- Пользователи должны быть импортированы со своими паролями и другими атрибутами

- Убедитесь, что импортированные пользователи могут войти на машину HQ-CLI

<br/>

<details>
<summary>Решение</summary>
<br/>

#### Импорт пользователей
Монтируем образ Additional.iso и 
```yml
mount -o loop /dev/sr0 /mnt/ -v
ls -l /mnt/
```
Посмотрим файл с пользователями
> Обратите внимание на пароль, чтобы его вписать в скрипт!! в данном решении пароль представлен - P@ssw0rd1
```yml
less /mnt/Users.csv
```
Импортируем пользователей в файл `users_fix.csv`, пропустив неисправные данные. 
```yml
iconv -f UTF-8 -t UTF-8//IGNORE /mnt/Users.csv > /root/users_fix.csv
```

Создаем баш-скрипт для импорта пользователей в самба.
```yml
cat << "EOF" > import.sh
#!/bin/bash

while IFS=';' read -r name fam role phone ou street zip city country pass; do
    username="${fam}_${name}"
    samba-tool user create "${username,,}" "P@ssw0rd1" --given-name="$name" --surname="$fam" --job-title="$role" --telephone-number="$phone"
    [[ -n "$ou" ]] && samba-tool ou create "OU=$ou" 2>/dev/null
    [[ -n "$ou" ]] && samba-tool user move "${username,,}" "OU=$ou" 2>/dev/null
done < users_fix.csv
EOF
```

Запускаем скрипт, он будет работать долго
```yml
bash import.sh
```

Для просмотра импортированных пользователей введем команду:
```yml
samba-tool user list
```

Для просмотра конкретного пользователя:
```yml
samba-tool user show <имя пользователя>
```

После импорта переходим на HQ-CLI и заходим под любым пользователем, вводим пароль **P@ssw0rd1**

## Задание 3

### Перенастройте ip-туннель с базового до уровня туннеля, обеспечивающего шифрование трафика

- Настройте защищенный туннель между HQ-RTR и BR-RTR
  
- Внесите необходимые изменения в конфигурацию динамической маршрутизации, протокол динамической маршрутизации должен возобновить работу после перенастройки туннеля

- Выбранное программное обеспечение, обоснование его выбора и его основные параметры, изменения в конфигурации динамической маршрутизации отметьте в отчёте.

<br/>

<details>
<summary>Решение</summary>
<br/>

#### Настройка HQ-RTR

```yml
en
conf
crypto-ipsec ike enable
crypto-ipsec profile CIPROFILE ike-v2
mode tunnel
ike-phase1
proposal aes256-sha256-modp2048
auth pre-shared-key P@ssw0rd
exit

ike-phase2 
protocol esp 
proposal aes256-sha256 
local-ts 172.16.1.2
remote-ts 172.16.2.2
end

conf
crypto-map CMAP 10
match peer 172.16.2.2
set crypto-ipsec profile CIPROFILE 
end

conf
filter-map ipv4 FMAP 5
match gre host 172.16.1.2 host 172.16.2.2
set crypto-map CMAP peer 172.16.2.2
exit

filter-map ipv4 FMAP 10
match udp host 172.16.2.2 eq 4500 host 172.16.1.2 eq 4500
set crypto-map CMAP peer 172.16.2.2
exit


filter-map ipv4 FMAP 15
match any any any
set accept
exit

interface isp
set filter-map in FMAP 10
exit

interface tunnel.0
set filter-map in FMAP 10
end

wr mem
```

filter-map ipv4 TO_ISP
