## Задание 1

### Выполните импорт пользователей в домен au-team.irpo:

- В качестве файла источника выберите файл users.csv располагающийся в образе Additional.iso

- Пользователи должны быть импортированы со своими паролями и другими атрибутами

- Убедитесь, что импортированные пользователи могут войти на машину HQ-CLI

#### Импорт пользователей
Монтируем образ Additional.iso и 
```yml
mount -o loop /dev/sr0 /mnt/ -v
ls -l /mnt/
```
Посмотрим файл с пользователями
> Обратите внимание на пароль, чтобы его вписать в скрипт!! в данном решении пароль представлен - P@ssw0rd1
```yml
less /mnt/Users.csv
```
Импортируем пользователей в файл `users_fix.csv`, пропустив неисправные данные. 
```yml
iconv -f UTF-8 -t UTF-8//IGNORE /mnt/Users.csv > /root/users_fix.csv
```

Создаем баш-скрипт для импорта пользователей в самба.
```yml
cat << "EOF" > import.sh
#!/bin/bash

while IFS=';' read -r name fam role phone ou street zip city country pass; do
    username="${fam}_${name}"
    samba-tool user create "${username,,}" "P@ssw0rd1" --given-name="$name" --surname="$fam" --job-title="$role" --telephone-number="$phone"
    [[ -n "$ou" ]] && samba-tool ou create "OU=$ou" 2>/dev/null
    [[ -n "$ou" ]] && samba-tool user move "${username,,}" "OU=$ou" 2>/dev/null
done < users_fix.csv
EOF
```

Запускаем скрипт, он будет работать долго
```yml
bash import.sh
```

Для просмотра импортированных пользователей введем команду:
```yml
samba-tool user list
```

Для просмотра конкретного пользователя:
```yml
samba-tool user show <имя пользователя>
```

После импорта переходим на HQ-CLI и заходим под любым пользователем, вводим пароль **P@ssw0rd1**
